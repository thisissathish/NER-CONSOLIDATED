  4. How to Run the Unified System

  Option A: Using the Windows Batch Scripts

  Double-click QUICK_START.bat or START_SYSTEM.bat in
  E:\Mark2\ner-logistics-platform.

  Option B: Using the Command Line

  # 1. Start Database & Redis
  cd E:\Mark2\ner-logistics-platform\backend
  docker compose up -d

  # 2. Activate Python Environment & Set Path
  source venv/Scripts/activate       # (or venv\Scripts\activate on Windows CMD)
  export PYTHONPATH=$(pwd)           # (or set PYTHONPATH=%cd% on Windows CMD)

  # 3. Initialize & Seed (First Time Only)
  python -m app.scripts.init_db
  python -m app.scripts.load_sample_roads
  python -m app.scripts.seed_synthetic_data
  python -m app.ml.train_risk_model
  python -m app.ml.score_segments

  # 4. Start the FastAPI Server
  uvicorn app.main:app --reload

  - Interactive API Docs: http://localhost:8000/docs
  - Live Visual Map: Open dashboard.html in your web browser.
